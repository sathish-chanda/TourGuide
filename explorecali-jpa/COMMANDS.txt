We built this project using spring initilizer with the following dependencies. 
a. Spring Web
b. Rest Repositories
c. Spring Data JPA 
d. H2 Database
e. Lombok

### BUILD and RUN commands ####

1. cd explorecali-jpa 
2. mvn clean install ---> to build the project
3. java -jar target/explorecali-jpa-0.0.1-SNAPSHOT.jar   ---> to run the project
4. curl localhost:8080 ---> to test if the project is running.

### Build and run the using the image

1. Add the mvn jib dependencies
2. mvn jib:dockerBuild [take our application turn into an image]
3. docker images
4. docker run -p 8080:8080 explorecali-jpa:0.0.1-SNAPSHOT
5. open localhost:8080
6. docker stop containerID

### Storing data in persistant storage :: mysql
1. Update the pom.xml file to have the dependencies spring-boot-docker-compose [This helps to connect containers], mysql-connector-j
2. Create file compose.yml which will have the configurations of the mysql database.
3. $ mvn install spring-boot:run
4. The above command will download and launch the mysql in the background which will be used by the application.
5. $ docker exec -it mysqlcontainerID mysql -u [root/myuser] -p 
6. The above command used to connect to mysql database
7. $ SHOW DATABASES;
8. $ SHOW TABLES;
9. $ select * from tour;
